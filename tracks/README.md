# tracks/ — Race Track Data

This folder contains track generators and saved track data files.

## Files

| File | Description |
|---|---|
| `createPracticeTrack.m` | Generates the practice circuit (~325 m). Run automatically by `practiceRace` if needed. |
| `createMysteryTrack.m` | **INSTRUCTOR ONLY** — generates the championship circuit. Do not share with students. |
| `practiceTrack.mat` | Auto-generated on first `practiceRace` run. Safe to commit. |
| `mysteryTrack.mat` | Generated by instructor before championship. **NOT in the repo** (see .gitignore). |

## Generating Track Files

```matlab
% Students — done automatically:
practiceRace    % generates practiceTrack.mat if missing

% Instructor — before championship:
cd AI_Grand_Prix
addpath tracks
trackData = createMysteryTrack();
save tracks/mysteryTrack.mat trackData
```

## Track Format

Both generators return a `trackData` struct:

| Field | Size | Description |
|---|---|---|
| `centreline` | N×2 | [x, y] centreline waypoints (m) |
| `width` | 1×1 | Track width (m) |
| `normals` | N×2 | Unit normals pointing left of travel |
| `leftBoundary` | N×2 | Left track edge |
| `rightBoundary` | N×2 | Right track edge |
| `cumDist` | N×1 | Cumulative arc-length (m) |
| `lapLength` | 1×1 | Total lap length (m) |
| `startFinishLine` | 1×4 | [x1 y1 x2 y2] finish line segment |
| `name` | string | Track name |
