MCP

WHAT IT IS

MathWorks' MATLAB MCP server (pinned by setup). It lets the agent run MATLAB code and read the result. In Part 1 it is only for the optional MATLAB experiment in your proposal, and only if you ask; in Part 2 it runs every race.

WHERE IT RUNS

On your PC: it starts your MATLAB (with its desktop) on first use, which takes about a minute, in the AI_Grand_Prix folder.

NEEDS

Your MATLAB licence. Base MATLAB is enough.

THE TOOLS IT GIVES THE AGENT

evaluate_matlab_code(code) ● used in the workshop

run a few lines and read the output (practiceRace, garage …)

run_matlab_file(path)

run a script file

check_matlab_code(path)

the Code Analyzer's warnings

run_matlab_test_file(path)

run unit tests

detect_matlab_toolboxes

which toolboxes are installed

In the agent panel you see: a tool-call card evaluate_matlab_code with the MATLAB code it ran, then MATLAB's printed output.
