SKILL

literature-review

Turns the PDFs into text, fills one evidence row per paper, writes the review and 3 candidate gaps; you pick one.

  • evidence.csv: method · finding · limitation · where
  • review.md: 3–5 themes, every claim cited [rank]
  • Proposal with a Figure brief and a pending MATLAB experiment

WHAT IT USES

SCRIPT

pdf_to_text.py [--fast]

Docling (IBM): page-layout + table models, all PDFs → Markdown; matches each to its rank → index.csv

FILES

MCP
