The back-up converter

MCP

WHAT IT IS

Microsoft's MarkItDown as an MCP server: it turns a file (PDF, Word, PowerPoint, Excel, HTML) into Markdown text the agent can read.

WHERE IT RUNS

On your PC. Antigravity starts it with the others; it only works when the agent calls it.

NEEDS

Nothing: no key, no internet for local files.

THE TOOL IT GIVES THE AGENT

convert_to_markdown(uri) ● used in the workshop

one file → Markdown, e.g. uri = "file:///C:/.../3_papers/pdf/03_Kabzan_2019.pdf"

In the agent panel you see: a tool-call card convert_to_markdown with a file:/// address. You should rarely see it: Docling comes first.
