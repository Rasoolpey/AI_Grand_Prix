AI Workshop · Part 1

The research-figure skill runs PaperViz, Google Research's figure method (Planner, Stylist, Visualizer, Critic), inside the agent: it writes and refines the figure description with PaperViz's own prompts and style guide, draws it with Antigravity's built-in image generation (no key, no cost), and critiques it up to twice. Students check every label before using the figure. The MATLAB section states one testable claim, the baseline it is compared against, and the metric.
