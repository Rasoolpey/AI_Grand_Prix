PART 1 · TOOL · SCRIPT pdf_to_text.py + Docling

STEP 4

From PDF to text the agent can read

SCRIPT

WHAT IT IS

A Python program in the literature-review skill. It uses Docling, IBM's open-source document converter, to turn every PDF into Markdown with headings, paragraphs and tables, then matches each text to its paper.

WHERE IT RUNS

In the terminal, on your PC: Docling's page-layout and table AI models run on the processor (downloaded by setup). About 1–2 s per page: a few minutes for 15 papers. --fast: quicker, rougher tables.

NEEDS

Nothing online. Your PDFs in 3_papers\pdf\.

WHAT IT DOES

convert ● used in the workshop

3_papers/pdf/*.pdf → 3_papers/text/<same name>.md (only new or changed PDFs)

match ● used in the workshop

each text to its rank: file name (03_Kabzan_2019), ScienceDirect PII, DOI on page 1, or title

index ● used in the workshop

3_papers/text/index.csv, and the list of abstract-only papers (no PDF)

fallback

no Docling? it uses MarkItDown instead and says so (lower quality)

In the agent panel you see: one terminal command and its progress, file by file; then the agent opens the texts (built-in file reading).
