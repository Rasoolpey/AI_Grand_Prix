PART 1 · YOUR AGENT'S TOOLBOX

Four kinds of tools, each step its own mix

SKILL

A recipe in a text file

.agents\skills\<name>\SKILL.md. The agent reads it when your request matches its description, then follows it step by step.

research-question · literature-search · literature-review · research-figure · research-report · grill-me · grilling

MCP

A program that gives the agent named tools

Antigravity starts it on your PC; the agent calls its tools like functions, e.g. scopus_get_abstract(doi). MCP = Model Context Protocol, the standard plug.

scopus · google-scholar · markitdown · matlab

SCRIPT

A Python program the agent runs in the terminal

Inside a skill's scripts\ folder, run with the workshop's own Python (..\.tools\py). Fixed rules, same result every time.

scopus_q1.py · pdf_to_text.py (Docling) · build_report.py

BUILT-IN

What the agent can do by itself

Read and write files, run terminal commands, ask you questions, and generate images. No extra install.

files · terminal · image generation

See what is running: the agent says which skill or tool it uses, and why, before it uses it (a rule in AGENTS.md). Every tool call and terminal command shows up in the agent panel; terminal commands may wait for your OK.

AI Workshop · Part 1 · the next slides show each tool just before the step that uses it

The one idea: an agent is a model plus tools. A skill is a recipe, an MCP server is a box of named functions, a script is a program with fixed rules, and the built-ins are the agent's own hands. Each step of Part 1 uses a different mix; the tool map on the next slide shows which. The MCP list lives in one file for every folder: %USERPROFILE%\.gemini\config\mcp_config.json.
