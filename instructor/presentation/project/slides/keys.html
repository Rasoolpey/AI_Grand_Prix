AI Workshop · Setup · shared keys, deleted after the workshop

The instructor shares one file, workshop_keys.env, with shared keys for Scopus, SciDraw AI and Gemini (PaperViz). Setup finds it in Downloads, Documents, the Desktop or next to the zip and writes the keys into AI_Tools\my_keys.env, so students answer no key questions. Never post the file publicly; the keys are deleted after the workshop. The Antigravity extension uses the student's own Google account; Google Scholar and MarkItDown need nothing.
