STEP 2

The Q1 filter: papers come only from here

SCRIPT

WHAT IT IS

A Python program in the literature-search skill. It searches Scopus with your queries and keeps only journal articles and reviews from IEEE or Elsevier in Q1 journals (CiteScore percentile ≥ 75 in at least one subject area).

WHERE IT RUNS

In the terminal, on your PC, with the workshop Python: ..\.tools\py\Scripts\python.exe .agents\skills\literature-search\scripts\scopus_q1.py search .... It calls Elsevier's Scopus Search API and Serial Title API (journal rank).

NEEDS

Your Scopus key, read from my_keys.env (never printed); on campus or the VPN. Standard Python only.

ITS COMMANDS

search "QUERY" ... --since 2015 ● used in the workshop

40 most relevant + 15 most cited per query, Q1 check → candidates.csv (with abstracts) + search_log.md

add "<DOI or exact title>"

checks a paper found elsewhere (Google Scholar); only Q1 papers are added

finalize ● used in the workshop

refills papers.csv from the Scopus records, drops anything not a candidate, ranks: relevance → citations/year → recency

selftest

one search and one journal lookup, to test the key

In the agent panel you see: a terminal command (approve it if asked) and its output: how many candidates each query gave.

AI Workshop · Part 1 · tool: script scopus_q1.py

Why a script and not the agent: the filter must be the same every time and nothing invented can slip in. finalize overwrites every title, author and DOI with what Scopus says. Options students can set in my_instructions.md: --publishers ieee,elsevier,springer (or any), --max-quartile 2, --since.
