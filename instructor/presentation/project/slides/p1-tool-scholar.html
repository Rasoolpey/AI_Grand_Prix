MCP

WHAT IT IS

An MCP server (github.com/JackKuo666/Google-Scholar-MCP-Server, pinned) that searches Google Scholar. Useful for papers Scopus missed, but Scholar does not check quality, so every find must pass the Q1 filter: scopus_q1.py add.

WHERE IT RUNS

On your PC: it reads Google Scholar's public web pages. Heavy use can be slowed down or blocked by Google.

NEEDS

Nothing: no key.

THE TOOLS IT GIVES THE AGENT

search_google_scholar_key_words(query, num_results) ● used in the workshop

a keyword search: titles, authors, links

search_google_scholar_advanced(query, author, year_range)

the same, by author or years

get_author_info(author_name)

an author's profile and top papers

In the agent panel you see: a tool-call card search_google_scholar_key_words, then a terminal command scopus_q1.py add ...: only papers it reports as ADDED count.
