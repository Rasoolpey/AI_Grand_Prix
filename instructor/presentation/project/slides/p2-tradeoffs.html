Mass: every upgrade but tyres and gearing adds kilograms

Physics: grip ↔ rolling loss · downforce ↔ drag · pull ↔ top speed

Three reasons no car wins everywhere: the budget, mass, and the physics built into each part. Go down the table and ask the room which path pays for each gain. Example: soft tyres win time on the technical circuit but cost energy on the endurance; the downforce kit helps the endurance's fast corners but its drag can make the starting car run short of energy.
