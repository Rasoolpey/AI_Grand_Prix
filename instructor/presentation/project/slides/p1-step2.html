SKILL

literature-search

Writes 3–5 Scopus queries from your brief, runs a filtered search, then judges relevance from the abstracts.

  • Only journal articles and reviews
  • Only IEEE and Elsevier, only Q1
  • Relevance 0–3, keeps the 30–40 best
  • No paper that Scopus did not return

WHAT IT USES

SCRIPT

scopus_q1.py search "QUERY" … --since 2015

Scopus Search API + journal rank (Serial Title API): CiteScore percentile ≥ 75 = Q1 → candidates.csv

SCRIPT

scopus_q1.py finalize

refills every field from Scopus, drops anything invented, ranks: relevance → citations/year → recency

MCP

google-scholar · search_google_scholar_key_words(query, num_results)

optional extra; each find must pass scopus_q1.py add "<DOI>"

MCP

scopus · scopus_search(query, count)

quick hit count to test a query before the real search

AI Workshop · Part 1 · step 2 of 6

Show the queries the agent proposes before it searches and ask students to check them against their keywords. Options students can ask for in my_instructions.md: --publishers ieee,elsevier,springer (or any), --max-quartile 2, --since. Q1 here is Scopus's CiteScore quartile: the journal is in the top 25 % of at least one of its subject areas. About 15 minutes.
