AI Workshop · Setup · a shared key, deleted after the workshop

The instructor shares one file, workshop_keys.env, with a shared Scopus key. Setup finds it in Downloads, Documents, the Desktop or next to the zip and writes it into AI_Tools\my_keys.env, so students answer no key questions. Never post the file publicly; the key is deleted after the workshop. The figure (PaperViz) needs no key: the agent draws it with Antigravity's built-in image generation. The Antigravity extension uses the student's own Google account; Google Scholar and MarkItDown need nothing.
